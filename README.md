# JakBall24h0bot - Crypto Update Telegram Bot

🤖 A Telegram bot providing real-time cryptocurrency updates, price tracking, and blockchain alerts.

## Features

- Real-time cryptocurrency prices
- Latest crypto news
- Market trends and analysis
- Blockchain alerts
- 24/7 updates

## Deployment

This bot is deployed on Railway using GitHub integration.

## Commands

- `/start` - Welcome message and main menu
- `/help` - List all available commands
- `/price` - Get current crypto prices
- `/news` - Latest crypto news
- `/settings` - Customize preferences
- `/channel` - Join our crypto channel

## Environment Variables

- `BOT_TOKEN` - Your Telegram bot token
- `PORT` - Port for webhook (Railway sets this automatically)
- `RAILWAY_STATIC_URL` - Railway URL (set automatically)
